# Dad Joke Showdown

Entry for the [Dad Joke Showdown](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5?ref=41fw6r6c) competition on [make.fun](https://make.fun/r/41fw6r6c) (`program/v1`).

## Usage

Runs on Node 22+ (`main.ts` requires no build step or external dependencies) and writes a single deterministic UTF-8 dad joke (`<= 200` characters) to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when testing locally):

```bash
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
